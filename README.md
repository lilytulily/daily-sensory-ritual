## 🟠 產品概述（Overview）

一個結合「個人特質 × 當下狀態 × 環境條件」的感官儀式生成器，

將抽象的能量、占星與五行概念，轉譯為**可在日常中實踐的微行動建議**。

再依使用者的選擇，藏入SCP模式。

Next.js + Tailwind CSS +Framer Motion庫

### **▌核心價值主張（Value Proposition）**

- 不預測未來，只照顧今天，並非占卜。
    
    <aside>
    
    - 不要求努力，而是提供「剛剛好的行動指引」
    - 讓使用者感覺「有下一步可以做、被安放在某個位置」
    - 藉由互動感和資訊陳列揭露給使用者滿足感
    </aside>

### **▌流程簡介**

使用者腳色與使用情境

<aside>

- 進入產品（Entry Point）
    - 使用者可直接進入體驗流程，**不需登入 / 註冊**
    - 首次使用預設為完整流程
- 輸入暱稱/生日
    - 暱稱為 string (10)
    - 此為「相對穩定資訊」，設計上視為**一次性輸入**
    - 主要用於建立個人能量基底（星座傾向）
- 今日日期/使用者地點
    - 系統自動抓取當日當時當地
    - 日期/所在地做為天氣使用
- 選擇今日狀態與感官偏好
    - 今日情緒 / 心境 （單選）
    - 感官偏好（分項多選）
    - 互動式圖卡選擇（分項多選）
    - 今日目標（必寫自由文字，1 句）
    - 此區塊為「主觀輸入」，不判斷對錯
    - 所有選項僅影響輸出內容的語氣與建議方向
    - 不做心理診斷或狀態評分
- 系統計算與生成內容
    - 系統會將所有輸入轉換為「能量參數」
    - 能量參數僅為內部邏輯使用，不顯示給使用者
    - 使用 rule-based engine
    - 不使用機器學習或即時學習模型
- **SCP 模式觸發條件**
    - 系統將根據使用者所選狀態之 SCP 權重進行加總判定
    - 做完所有流程當總權重 ≥ **+4** 時觸發
    - 做完daystep但計算後年齡 ≥ 100歲時觸發
    - 權重與判斷規則不對使用者揭示
    - 觸發後背景也變更為SCPbackground
- 結果頁：Daily Sensory Ritual | 每日使用說明書
    - 單一頁面呈現完整內容
    - 包含
        1. 能量空間配方（生活風格建議）
        2. 微儀式神諭（每日任務）
        3. 感官下午茶建議
        (待補充)
    - 所有建議皆為「生活風格層級」
    - 不包含醫療、心理治療或功效保證
- 結果頁：過渡行為指引（Transition Cue）※SCP 專屬 
(待補充)
</aside>
